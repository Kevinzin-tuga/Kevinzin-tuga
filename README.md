## About me

Right now my work is split into three areas:

- **Minecraft mods/plugins** — Client-side Fabric mods and server plugins that help server developers and players. Published on CurseForge, including **AutoLoot Selector** and **MapArt Maker** (under construction), with over **100 downloads!**
- **Discord Bots** — Bots designed to help growing communities, currently previewing a multifunctional bot with several useful features.
- **Minecraft Design/Builds** — Designing textures and images for future projects, building worlds, cities, houses, castles and much more.
- **Languages** — Portuguese, English and Spanish.
